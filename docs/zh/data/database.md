# 数据库说明

ETKvNext 使用 PostgreSQL 保存运行数据。数据库由 Compose 中的 `db` 服务提供，数据保存在 `postgres_data` 卷；配置文件和持久化辅助文件保存在 `/config` 映射目录。

本页只说明业务域，不列出容易随迁移变化的完整表结构。具体字段应以当前迁移文件和代码中的 Repository 为准。

## 主要业务域

- **平台**：配置 revision、审计事件和迁移记录。
- **身份**：ETKN 用户、邀请、权限模板、个人偏好和 Telegram ID。
- **媒体**：影视身份、季度/分集、媒体版本、媒体流、图片资产和外部身份。
- **资源**：115 文件缓存、分享入库、共享源、虚拟入库和资源获取状态。
- **订阅**：追剧季度、订阅需求、演员订阅、合集补齐和订阅助手快照。
- **任务**：根任务、任务项、阶段状态、事件日志、自动计划和重试信息。
- **整理**：原始路径、目标路径、入库方式、未识别记录、纠错和重组历史。
- **播放**：当前会话、最近播放记录和统计汇总。

## 迁移规则

- 迁移文件按版本执行，已经应用的迁移不应直接改写。
- 生产升级由容器启动时的迁移流程完成，先确认数据库 healthy 再检查应用健康接口。
- 旧版 ETK 数据库不会因为启动 ETKvNext 自动搬运；迁移旧数据必须使用明确的迁移方案。
- 任务历史、整理记录和媒体缓存属于业务资产，排障时不要直接删除数据库记录代替正常清理流程。
