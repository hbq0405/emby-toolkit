# ETKvNext 文档

> 当前文档按 ETKvNext `v1.3.21` 的实际功能整理。新版的配置、任务和媒体服务已经独立于旧版 ETK；旧版 Wiki 地址仍然保留，但不再代表旧版程序的使用方式。

ETKvNext 是一套面向家庭和小型媒体库的资源获取、整理、订阅、播放和维护工具。它把 115、共享资源、Telegram 频道、MoviePilot 和 re0 接到同一条可追踪的任务链里：资源进入后，系统可以继续完成识别、整理、元数据、媒体信息、字幕/图片和媒体库更新。

## 第一次使用

1. 阅读 [快速开始](/zh/guide/quick-start)，用 Compose 启动 `etkn` 和 PostgreSQL。
2. 打开 [首次配置](/zh/guide/first-run)，创建或确认 ETKN 管理员账号，完成 115 和 TMDb 授权。
3. 按需要配置 [媒体管理](/zh/guide/media-management)、[资源中心](/zh/guide/shared-resource) 和 [订阅中心](/zh/guide/subscribe-assistant)。
4. 把第一部电影或一整季剧集送入待整理目录，在 [任务中心](/zh/guide/scheduler) 查看完整链路。

## 现在能做什么

- **资源获取**：浏览共享池、频道监听、MoviePilot 和 re0 资源；也可通过 Telegram Bot 搜索、订阅或提交分享链接。
- **115 整理入库**：识别电影、剧集、季度和分集，按分类与命名规则整理，生成 STRM/字幕，并继续完成刮削和媒体库更新。
- **分享入库**：直接检查 115 分享链接并入库，不要求先把分享转存到自己的目录。
- **媒体管理**：浏览媒体库，搜索、排序、编辑元数据和图片，刷新元数据，重建 MediaInfo，处理片头片尾和重复版本。
- **订阅追更**：统一管理智能追剧、演员订阅、TMDb 合集补齐和影视探索订阅，并按资源来源顺序处理需求。
- **洗版**：按分辨率、编码、HDR、音轨、字幕、纯净版和发布组等条件比较新旧版本，决定是否替换。
- **虚拟媒体库**：用榜单、规则、指定路径或个人推荐生成内置媒体服务中的媒体库；部分能力需要 Plus/Pro。
- **播放与观测**：ETKN 自带 Emby 兼容媒体服务，可查看当前播放、最近记录和统计；非本地资源按直链/302 播放。
- **自动维护**：任务中心支持手动任务、自动任务链、历史保留、失败重试和只读智能排查。
- **多用户**：管理员可创建模板、生成邀请链接和管理用户；普通用户只能访问被授权的个人入口。

## 重要边界

- ETKN 自带媒体服务，外部 Emby 不是新版主流程的前置条件。Wiki 不再按“安装 Bridge 插件后才能使用”的旧版流程说明。
- Compose 默认已经包含 PostgreSQL；只有使用已有数据库时，才需要自行调整数据库服务和环境变量。
- `5257` 是管理控制台和 API 端口，`8097` 是内置媒体服务端口。两个端口都要按实际网络访问方式配置。
- 115、共享池、MoviePilot、Telegram 频道和 AI 都是可选接入；未授权的服务不会自动参与任务。
- 旧版数据不会在新版启动时自动搬运。迁移旧库前应先确认迁移工具和数据范围，不能让两个版本同时处理同一待整理目录。
