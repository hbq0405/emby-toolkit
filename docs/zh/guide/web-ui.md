# Web 控制台

入口默认是 `http://服务器IP:5257`。新版登录的是 ETKN 账号，管理员和普通用户看到的菜单不同。

## 管理员菜单

- **资源中心**：共享池、频道监听、MoviePilot 和 re0。
- **订阅中心**：订阅总览、智能追剧、演员订阅、合集补齐和影视探索。
- **媒体管理**：配置虚拟/榜单媒体库，预览内置媒体服务中的媒体项。
- **增强功能**：封面生成、监控上传、自动打标、媒体去重和分享入库。
- **任务中心**：当前任务、历史任务、自动任务和任务工具箱。
- **正在播放**：当前会话、播放记录和统计。
- **整理记录**：整理账本、纠错、重组、事件历史和清理操作。
- **个人中心**：账户、密码、Telegram ID 和个人偏好。
- **基础设置**：服务授权、模块配置、系统运维和用户权限。

## 配置保存

设置中心按模块保存。每个模块有自己的保存按钮和版本号；如果提示“配置已被其他操作更新”，先刷新页面再保存，避免覆盖别人刚保存的内容。

敏感信息只显示是否已配置，不会在页面中回显完整凭据。

## 任务和日志

任务中心分为：

- **当前任务**：正在运行或排队的任务。
- **历史任务**：按全部、完成、失败、取消等状态查看历史。
- **自动任务**：配置任务链、单项定时任务和 CRON。
- **任务工具箱**：手动运行已接入的维护任务。

打开任务详情后，可以查看根任务、处理项、阶段时间线、后续任务、实时/历史日志和失败原因。任务标题优先使用片名或剧名，编号只作为辅助信息。

## 用户权限

管理员可以通过“用户与权限”创建用户、权限模板、邀请链接、有效期和媒体库范围。普通用户只能使用授权给自己的入口；个人 Telegram ID、播放账号和界面偏好在个人中心维护。
