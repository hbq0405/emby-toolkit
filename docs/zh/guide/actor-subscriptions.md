# 演员订阅

演员订阅会持续关注指定演员的新作品，并把符合条件的电影或剧集加入订阅需求。

## 使用步骤

1. 进入 **订阅中心 → 演员订阅**。
2. 搜索并选择演员。
3. 配置电影/电视剧范围、类型包含或排除条件，以及是否补齐历史作品。
4. 保存后手动刷新，或等待演员订阅任务按计划运行。

## 处理结果

- 已有作品会先按 TMDb 身份匹配，避免重复添加。
- 新作品会进入统一订阅和资源获取流程，后续由 MoviePilot、共享池、re0 等可用来源处理。
- 任务中心可以查看本次刷新新增了哪些订阅，整理记录可以查看最终是否入库。

演员订阅需要 TMDb 资料；如果希望自动下载资源，还需要配置至少一个可用资源来源。它不要求额外连接外部 Emby，播放和媒体展示由 ETKN 内置媒体服务提供。
