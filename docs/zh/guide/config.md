# 配置项总览

新版按功能模块保存配置。进入某个模块后只保存这一块内容，页面会显示“未保存更改”，不会要求把所有设置一次性提交。

## 服务和数据源

- **115 网盘**：OpenAPI、Cookie、目录、请求策略、STRM 和网盘侧处理。
- **媒体库**：媒体库主目录、内置媒体服务、虚拟媒体库、默认音轨/字幕和缺失集占位。
- **数据源**：TMDb、Fanart、Bangumi 的 Key、语言和请求设置。
- **网络**：为外部数据源和资源服务配置代理。
- **AI**：翻译、文件名辅助识别、向量和任务智能排查。
- **TG 通知**：Bot Token、接收目标、通知类型和消息模板。

## 整理和媒体

- **整理**：分类、命名、季集识别、目录映射、词表和冲突处理。
- **元数据**：标题/简介翻译、人物资料、图片、字幕、截图和媒体信息策略。
- **智能追剧**：追剧刷新、片头片尾提取、完结和缺集处理。
- **合集补齐**：TMDb 合集扫描和缺失电影订阅。
- **封面生成**：媒体库和虚拟媒体库封面样式、标题、角标和图源。
- **监控上传**：本地目录到 115 目录的增量同步或上传后删除。
- **自动打标**：按媒体库和分级规则追加或移除标签。
- **媒体去重**：重复版本扫描、保留规则和确认后清理。

## 资源和订阅

- **共享池**：共享中心连接、共享源登记、虚拟入库、小号和贡献点相关能力。
- **分享入库**：直接导入 115 分享链接，不需要先转存到自己的网盘目录。
- **MoviePilot**：连接地址、账号、Webhook 和暂存文件接管策略。
- **频道监听**：在资源中心配置 Telegram 用户会话、白名单、关键词/正则和转存方式。
- **订阅中心**：来源优先级、电影/剧集搜索、追剧、演员、合集和统一订阅策略。
- **re0**：在资源中心配置授权、签到、积分、体积、分辨率和字幕筛选。

## 账户和系统

- **任务中心**：历史保留数量、前端显示哪些工作流、自动任务和任务链。
- **用户与权限**：用户模板、邀请链接、媒体库范围、有效期和管理员权限。
- **系统运维**：性能、连接池、压力测试、容器重启和更新操作。高风险操作请先确认当前任务没有运行。

## 凭据说明

AI Key、TMDb Key、Fanart Key、Telegram Bot Token、115 凭据和 MoviePilot 密码不会以明文回显到页面。授权状态只显示为“已配置/未配置”；更换凭据时按页面提示重新保存和测试。

未授权的可选服务不会自动触发任务。配置了服务但不希望使用时，还要关闭对应模块开关或移除来源排序。
