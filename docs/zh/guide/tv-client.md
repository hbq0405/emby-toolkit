# ETKN TV

ETKN TV 是原生 Android TV 客户端，面向遥控器与大屏使用。需要 **Android 7（API 24）及以上**和可访问的 ETKN 媒体服务器。

## 下载与连接

1. 从 [ETKN TV 公开发行页](https://github.com/hbq0405/etkn-tv/releases/latest) 下载适合设备的 APK。
2. 安装后自动发现局域网 ETKN，或手动填写媒体地址，例如 `http://服务器IP:8097`。
3. 使用 ETKN 账号登录。自定义端口或反向代理用户填写实际可访问地址。
4. 进入媒体库，选择影片并播放，检查画面、声音、字幕与进度保存。

电视与服务器不在同一网络时，自动发现可能不可用，改用手动地址。无需在电视上单独填写 115 Cookie。

## 遥控器怎么用

| 操作 | 行为 |
| --- | --- |
| 首页按上 | 唤出顶部菜单 |
| 确认键 | 播放时控制播放/暂停，菜单中确认选择 |
| 播放时按左/右 | 显示进度并控制快进/快退 |
| 播放时按下 | 打开完整控制栏 |
| 返回 | 关闭当前浮层或回到上级页面 |

控制栏提供下一集、音轨、字幕、质量等操作。下一集按实际可播放分集前进，季末可以继续下一季；没有下一集时不显示对应按钮。

## 版本、音轨与字幕

在详情页可以预选媒体版本、音轨与字幕后开始播放。默认语言和字幕优先级与网页个人中心同步。

手动选择“第 N 音轨”后，同剧同季按列表序号记住选择；某集没有这个序号会提示并按默认处理。选择自动选择可解除本季锁定，恢复默认策略。

片头片尾支持显示跳过按钮、自动跳过或关闭，依赖片源已有的明确标记。没有标记时不会凭进度猜测片头。

## 原盘、HDR 与质量

客户端具备原盘相关播放及字幕处理能力，可播放的 ISO/BDMV、视频、音频和 PGS/ASS 组合仍取决于片源与设备。部分设备需要软件解码或服务端适配，不能把格式名称视为所有电视上的兼容保证。

**质量** 菜单可以选择原画或其他档位；服务端启用自动转码并满足条件时，客户端可请求适配。详情见 [内网缓存与转码](/zh/guide/playback-cache)。

## 弹幕、翻译与探索

- 弹幕先由管理员在增强功能开启，再在播放器调整显示。
- 文本字幕翻译需要服务器 AI 配置和可用文本轨道。
- 影视探索、季度订阅和资源获取受实例权益与用户权限控制。
- “我的订阅 / 追更入库通知”默认关闭，开启后只跟踪有个人归属的订阅；系统通知也受电视权限与后台调度影响。

## 多用户与更新

首页头像处可以切换已登录用户或登录新用户。观看进度、偏好与可见媒体按账号隔离。

设置中检查更新，客户端会校验包名、版本、文件哈希与安装签名，再交给系统确认安装。APK 下载与系统安装完成是两步；电视仍需允许对应安装操作。
