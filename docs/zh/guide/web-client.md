# 网页客户端

不用额外安装播放器，在电脑或手机的浏览器里打开 ETKN，就能浏览媒体库、选择影片和继续观看。

## 打开与登录

访问 `http://服务器IP:8097/web/`，使用 ETKN 账号登录。如果改过媒体端口，把 `8097` 换成实际端口；使用域名时，在域名后加 `/web/`。

网页客户端与管理后台使用同一套账号。普通用户只能看到授权范围内的内容，管理员可以从页面上的管理入口进入后台。

## 从哪里找到影片

| 入口 | 可以做什么 |
| --- | --- |
| 首页 | 继续观看、打开媒体库、浏览最新入库 |
| 媒体库 | 按库浏览、排序，或进入类型、平台和公司分类 |
| 搜索 | 查电影、剧集、人物或音乐；也可用拼音首字母查找已建立索引的内容 |
| 收藏 | 找到当前账号收藏的影视内容 |
| 影视探索 | 查看可发现的影视并搜索资源；需要对应实例权益与用户权限 |

电影或剧集详情可以查看简介、双评分、演职员、版本与相关内容。人物可进入介绍与参演作品；平台、制作公司名称可进入对应片单。具体项目是否显示取决于元数据是否齐全。

## 开始播放

1. 打开影片详情，有多个版本时先选版本。
2. 选择播放或继续观看；剧集也可以在分集列表中选一集。
3. 在播放器中调整 **质量、音轨、字幕、倍速**。
4. 需要时打开弹幕、全屏，或切到下一集。

切换音轨只改变当前所选音轨。浏览器不支持该轨道时，服务端可能需要转换音频；“原画”也可能保留视频、只适配音频，并不保证所有轨道都由浏览器直接解码。

质量菜单与自动适配需要服务端允许转码。配置方式和网络适用范围见 [内网缓存与转码](/zh/guide/playback-cache)。

## 个人偏好

在 **个人中心** 调整默认音轨语言与字幕优先级，个人配置优先于全局配置；清空后跟随全局。网页与 TV 使用同一套个人偏好。

主题色、明暗、背景等外观设置由当前服务配置与用户可用选项决定。共享设备上可通过头像菜单切换账号，观看记录按账号区分。

## 管理员能做什么

管理员可从媒体卡片或详情的操作菜单编辑元数据、维护图片、刷新或删除媒体；批量操作只在有权限且页面支持时显示。删除前先确认是删除一个版本、整项媒体，还是同时处理云端文件。

## 播不了或一直缓冲

先确认同一影片在另一设备上的表现，再检查实际播放来源、缓存与转码状态。浏览器对 HEVC、DTS、TrueHD、HDR 和图形字幕的支持不同，不能只凭文件扩展名判断兼容性。按 [播放故障排查](/zh/faq/troubleshooting#播放失败或持续缓冲) 继续检查。
