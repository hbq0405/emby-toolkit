# 任务中心

任务中心是新版所有后台工作的统一入口。它把“现在在做什么”“以前做过什么”“下一步是否会继续”放在同一处。

## 当前任务

当前列表包含排队和运行中的任务。打开根任务可以看到：

- 电影、剧名或季度标题。
- 当前阶段和总体进度。
- 处理中的文件/分集。
- 已登记的后续任务。
- 实时日志和最近错误。

剧集通常以季度作为根任务，分集是内部处理项，不会在列表里变成很多个顶层任务。

## 历史任务

历史页可以按全部、完成、失败、取消等状态筛选，继续加载更早记录，并设置保留数量。历史任务不会因为当前筛选改变顶部总数。

失败任务可以按页面提供的选项重试失败阶段。重试前先看失败原因和是否存在重复提交风险。

## 自动任务

自动任务支持两种形式：

- **自动任务链**：按顺序执行多个步骤，前一步失败时后续步骤按依赖关系处理。
- **单项定时任务**：给一个已接入任务设置独立 CRON。

常见维护任务包括媒体元数据、人物资料、媒体信息、截图、搜索索引、网盘目录、追剧、演员订阅、共享资源维护、重复媒体扫描、评分同步和系统更新。

未在任务目录标记为“已接入”的功能不会出现在可运行列表里。

## 任务工具箱

工具箱用于临时执行维护任务。高风险任务会显示确认框，例如：

- 执行媒体去重会永久删除选中的多余版本。
- 清理分享来源可能联动删除其 STRM 和媒体版本。
- 清空回收站或未识别目录无法恢复。

先确认范围，再执行；不要用工具箱代替正常的历史任务恢复。

## 日志和智能排查

任务详情的日志只属于当前根任务和它登记的后代任务。下载日志时也会保留阶段、文件、来源和失败原因。

启用 AI 后可以使用“智能排查”：

- 读取任务、模块状态、容器状态、运行时指标和脱敏日志。
- 给出问题、证据和人工处理步骤。
- 不执行任意 SQL、Shell 或 Docker 命令。
- 不修改数据库、配置、媒体和任务。

AI 建议是辅助排查，遇到删除、重试和历史数据修复时仍需人工确认。
