# 字幕与 AI 翻译

先使用已有的合适字幕，缺少时再考虑翻译。字幕显示、文本翻译和完整字幕保存是不同步骤。

## 设置默认字幕

- **全局**：基础设置 → 媒体库 → 默认音轨与字幕。
- **个人**：个人中心 → 默认字幕；个人配置覆盖全局，清空后跟随全局。
- **本次播放**：在 Web 或 TV 播放器的字幕菜单中选择或关闭。

优先级可包含特效、简体、繁体、简英/繁英等双语及原语言。系统会结合当前内封与外挂字幕选择；修改偏好后，后续播放请求使用新规则，通常不需要重新扫描全库。

## 开启 AI 字幕翻译

管理员进入 **基础设置 → AI**：

1. 配置供应商、模型、凭据，并测试翻译连接。
2. 开启 **字幕翻译**。
3. 选择 **仅中文** 或 **中文＋原文双语**。
4. 保存后，在支持此功能的官方 Web/TV 播放器中选择可用翻译字幕。

中文简繁跟随当前账号字幕优先级，未设置个人偏好时跟随全局。已有中文文本的简繁转换可使用本地转换，不必为转换重复调用 AI。

::: tip 适用范围
翻译针对可读取的文本字幕，不是语音识别或图形字幕 OCR。只有 PGS、SUP 等图片字幕且没有文本轨道时，不能直接生成译文。第三方客户端不支持官方实时翻译界面；完整外挂的播放仍取决于客户端能力。
:::

## 播放中会发生什么

- 先检查已有字幕与可复用结果；可用的中心完整字幕优先复用。
- 没有合适结果时才按需提取文本并翻译。
- 建议配合内网自动缓存；原片完整缓存后可继续处理整轨字幕。
- 停止播放后不再提交新的翻译批次，在途批次可能继续保存；下次播放可续译。
- 仍有其他用户观看同一版本时，不会因为一个人退出就暂停全部处理。

模型、源字幕、网络和下载进度都会影响首次字幕出现时间。翻译暂不可用不代表视频本身损坏。

## 完整字幕保存在哪里

完成后将外挂字幕写入 **视频或 STRM 同目录**，需要该目录可写。写入成功后可清理对应内部临时副本；目录不可写或已有外挂内容冲突时保留内部结果，避免覆盖已有字幕。

完整外挂不会随着原片播放缓存淘汰而删除。尚未完成的翻译依赖缓存生命周期，缓存被淘汰后可能需要重新处理。

## 中心字幕共享

开启共享池且具备有效设备授权时，成功落盘的完整译文可在后台按真实视频身份共享到中心；部分译文不会作为完整字幕上传。同类型已有中心字幕时优先保留已有结果；上传失败不撤销本地外挂，也不为此重复翻译。

中心复用需要对应视频的有效身份和匹配的语言类型。未命中时继续本地处理，不代表中心能够为任意影片补出字幕。

## 没字幕时按这个顺序检查

1. 播放器是否选中了正确轨道，是否误选“关闭”。
2. 片源是文本字幕还是图形字幕，是否只有音轨没有字幕。
3. 个人优先级是否覆盖了全局选择。
4. AI 连接、模型和额度是否可用。
5. 需要保存完整外挂时，视频/STRM 目录是否可写。
