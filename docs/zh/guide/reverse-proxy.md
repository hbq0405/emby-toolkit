# 外部反向代理

ETKN 已自带管理服务和兼容 Emby/Jellyfin 的媒体服务。反向代理不是新版运行前提，只有在你需要域名、HTTPS、统一入口或公网访问时才需要配置。

## 需要代理哪些端口

- `5257`：管理页面、登录和管理 API。
- `8097`：内置媒体服务、虚拟媒体库和播放相关请求。

如果只使用管理页面，可以只代理 `5257`。如果还要让电视、手机或其他播放器访问媒体库，需要同时代理 `8097`，并在客户端填写代理后的媒体服务地址。

## 配置要点

- 保留 WebSocket 和长连接转发能力，避免任务日志流中断。
- 上传和请求体大小要覆盖封面、字幕以及批量配置的实际大小。
- 不要把容器内的 `127.0.0.1` 填给外部客户端，应填写客户端能访问的域名或局域网地址。
- 管理端和媒体服务端可以使用同一域名的不同路径，也可以使用两个域名；以实际代理规则和 ETKN 服务发现结果为准。
- 代理层只负责转发请求，不要自行缓存需要鉴权的管理响应。

虚拟媒体库本身由 ETKN 的 `8097` 媒体服务提供，不需要再部署旧版的独立反代程序。
