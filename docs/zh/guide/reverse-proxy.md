# 外部反向代理

需要域名、HTTPS 或公网访问时，将代理上游指向 ETKN 的实际媒体端口。新部署默认为 `8097`，网页、管理 API 和内置媒体服务共用该入口。

## 代理地址

例如上游是 `http://你的服务器:8097`，代理后的客户端地址是 `https://你的域名`：

- 网页客户端：`https://你的域名/web/`。
- 管理与个人中心：`https://你的域名/profile`。
- TV/兼容客户端：填写 `https://你的域名`。

`5257` 仅作为容器内回环 API 上游，不再作为外部代理目标。已有保存端口不一定是 `8097`，以当前配置为准。

## 配置要点

- 保留请求路径、查询参数、Range 与所需鉴权头。
- 支持长连接、事件流和 WebSocket，避免任务日志或更新通知被过早断开。
- 为封面、字幕和其他上传保留足够请求体大小。
- 不缓存需要鉴权的页面、管理响应和个人数据。
- 客户端与 STRM 地址使用真正可达的地址，不填容器内环回地址。

通过代理后是否识别为内网取决于真实客户端地址和服务端判断。公网访问保持其原有播放策略，不要通过伪造内网头强制开启缓存或转码。

## 配置完成后验证

1. 打开网页并登录，确认 JS、图片和 API 正常。
2. 在后台打开一个任务日志，观察连接是否持续。
3. 用 TV 或手机连接同一域名，浏览并播放一部影片。
4. 检查播放来源和所选音轨、字幕，跳转到另一个位置再确认。

只验证首页或健康接口不足以证明播放与长连接都可用。
