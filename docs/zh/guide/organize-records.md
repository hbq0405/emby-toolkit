# 整理记录

整理记录是新版的入库账本，用来回答“这个文件从哪里来、识别成了什么、最后放在哪里、现在能不能纠正”。

## 可以查看什么

列表支持按状态、媒体类型和入库方式筛选：

- 整理成功。
- 未识别。
- 质检不合格。
- 处理失败。
- 物理入库、分享入库、自分享入库和虚拟入库。

剧集按剧集组折叠展示，电影的多版本会聚合展示。打开记录可以查看名称变化、媒体身份、季度/分集、目标分类和处理事件。

## 纠错和重组

选择记录后可以手动指定：

- 电影或剧集身份。
- 季号、集号和剧集组。
- 目标分类。
- 入库方式。
- 是否合并为同一影视身份。

提交后会创建“手动重组整理记录”任务。任务完成后再回到记录页确认结果，不要在任务运行时重复提交相同记录。

## 删除边界

删除整理记录只删除记录和相关缓存，不代表删除 115 网盘物理文件。页面中的“清空未识别”和“清空回收站”是独立的高风险操作，执行前必须确认目录和回收站范围。

媒体版本删除、分享来源删除和网盘文件删除属于不同操作；看到确认提示涉及文件时，请先读完整提示再确认。
