# 快速开始

先让第一部影片可以播放，再逐步开启订阅、洗版和自动化。本页按 2026 年 11 月的统一入口说明，适用于当前 ETKN。

## 1. 准备并启动

准备 Docker / Docker Compose、可持久化的配置与媒体目录。默认部署带 PostgreSQL，不需要另装 Emby。

复制 [Docker 部署](/zh/guide/docker) 中的 Compose 示例，修改数据库密码后执行：

```bash
docker compose up -d
docker compose ps
docker compose logs --tail=100 etkn
```

## 2. 打开统一入口

```text
网页客户端：http://服务器IP:8097/web/
管理与个人中心：http://服务器IP:8097/profile
```

`8097` 是新部署默认媒体端口，管理页面、API 与媒体服务共用此入口。已有配置使用保存的端口，不要仅因示例写了 `8097` 就修改正在使用的端口。`5257` 是容器内 API 上游，不再要求对外发布。

使用 ETKN 管理员账号登录。初始密码未指定时，在首次启动的容器日志中查看生成结果，随后在个人中心修改。

## 3. 选择你的起步路线

| 已有内容 | 先做什么 | 需要什么 |
| --- | --- | --- |
| 115 网盘影视 | 服务授权 → 115；配置待整理、目标目录和整理规则 | 115 授权、TMDb 数据源、本地 STRM 目录 |
| 已有本地影视 | 映射媒体目录；配置媒体来源并刷新入库 | 容器可读取的路径、影视元数据配置 |
| 家庭视频 | 创建视频型指定路径媒体库并刷新 | 可读取的目录，无需强行匹配 TMDb |
| 本地音乐 | 创建音乐型指定路径媒体库并刷新 | 音频文件和尽量完整的标签 |

云盘和本地影视的目录含义不同。115 目录使用网盘目录选择器，本地目录填写容器路径，具体步骤见 [首次配置](/zh/guide/first-run)。

## 4. 验证第一部影片

1. 小范围提交一部电影或少量分集。
2. 在任务中心检查识别、整理、元数据、媒体信息与发布结果。
3. 到网页客户端搜索影片，打开详情并播放。
4. 检查画面、声音、字幕，以及退出后的续播进度。

生成 STRM 或“转存成功”只是一个阶段，最终入库与真实播放都需要分别确认。

## 5. 按需继续

- 电视观看：[安装 ETKN TV](/zh/guide/tv-client)。
- 下载与追更：[共享资源中心](/zh/guide/shared-resource)、[订阅中心](/zh/guide/subscribe-assistant)。
- 兼容播放：[内网缓存与转码](/zh/guide/playback-cache)。
- 观看体验：[字幕翻译](/zh/guide/subtitles)、[弹幕](/zh/guide/danmaku)、[音乐](/zh/guide/music)。

旧版 ETK 与 ETKN 不要同时处理同一待整理目录。启动数据库迁移不会自动迁入旧版数据；迁移前先核对迁移工具的范围与备份。
