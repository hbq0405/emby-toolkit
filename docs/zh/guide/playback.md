# 播放中心

播放中心用于观察真实播放情况，不是媒体库配置页。入口是左侧“正在播放”。

## 当前会话

显示正在播放、暂停或刚刚开始播放的会话，包括用户、媒体、来源和播放状态。它适合确认客户端是否真的发起了请求，以及当前播放的是哪个媒体版本。

## 播放记录

默认保留最近 7 天的开始、暂停和停止记录，可以按用户筛选，并继续滚动加载更早记录。播放记录不会替代任务日志：入库问题看任务中心，播放问题看播放中心。

## 播放统计

提供最近 7 天趋势、活跃会话、观看用户、点播次数、观看时长和热门媒体排行，用于观察真实使用情况。

## 远程资源播放规则

- 本地资源可由 ETKN 直接提供。
- 115、分享、共享池等非本地资源先解析源站直链，再以 `302` 交给客户端。
- ETKN 不按客户端 UA 或 Range 请求自动中转远程媒体流，也不把远程资源转码后兜底输出。
- 元数据、图片和字幕接口不属于媒体流规则，可以继续通过 ETKN 访问。

播放地址应填写客户端能访问的 ETKN 地址。容器内的 `127.0.0.1` 只对容器自身有效，不能直接拿给电视、手机或外部 Emby 客户端。
