# 播放中心

后台 **正在播放** 用于查看真实会话、历史与统计。开始看片请打开 [网页客户端](/zh/guide/web-client) 或 [ETKN TV](/zh/guide/tv-client)。

## 当前会话

查看播放用户、客户端、媒体版本、播放状态和进度。片名相同但版本不同，音轨与字幕也可能不同，排查时先确认是同一版本。

## 来源与转码信息

| 信息 | 含义 |
| --- | --- |
| 本地 | 正在使用服务器上的实体媒体 |
| `302` / 直链 | 解析远程地址后交由客户端读取 |
| 缓存 | 当前播放实际使用服务器播放缓存 |
| 视频/音频转码方法 | 描述编码处理；可能只转音频，也可能重新编码视频 |

来源和转码可以同时成立，例如读取缓存并适配音频。完整缓存、起播成功与整片播放完成也应分别判断。

同一会话结束后可在记录中查看最后的播放信息；切换媒体或重新播放会产生相应记录。不要仅用一次直链解析事件推断最终视频传输路径。

## 播放记录

默认保留最近 7 天的开始、暂停和停止记录，可按用户筛选并滚动查看留存记录。播放问题看这里；资源尚未入库时看任务中心与整理记录。

## 播放统计

最近 7 天趋势、观看用户、点播次数、时长和热门媒体排行帮助了解使用情况。统计由播放回调与会话记录形成，不等于文件下载量，也不证明客户端实际完整看完。

## 远程资源的适用规则

默认解析直链/302；开启 **内网自动缓存** 后，服务端识别为内网的请求可边下载边播放。公网或未知地址不自动套用内网缓存。官方客户端的可选转码另有开关与适用条件。

详见 [内网缓存与转码](/zh/guide/playback-cache)。客户端地址必须可达，不能把容器内的 `127.0.0.1` 填给手机或电视。
