# 弹幕

弹幕按播放需要获取。服务默认关闭，开启后可选择内置平台或自己的弹幕 API。

## 配置入口

管理员打开 **增强功能 → 弹幕**。弹幕已从基础设置中独立出来，在基础设置找不到是正常的。

1. 打开 **启用弹幕服务**。
2. 选择 **内置弹幕** 或 **自定义 API**。
3. 完成对应配置并点击 **保存弹幕配置**。
4. 回到官方 Web/TV 播放器，打开弹幕。

## 两种来源

| 来源 | 怎么配置 |
| --- | --- |
| 内置弹幕 | 按需选择 B站、腾讯、爱奇艺、优酷、芒果等平台 |
| 自定义 API | 填写可由 ETKN 服务器访问的 HTTP(S) 弹弹兼容 API 根地址，支持路径前缀 |

可接入使用兼容接口的自建服务，例如御坂。填写地址时以所部署服务的 API 根路径为准，不要直接粘贴某部影片的播放页。地址保存在服务端，由服务端访问。

## 播放器里怎么调

Web/TV 播放器中打开 **弹幕**，按客户端提供的选项调整开关、行数、字号、不透明度和速度。后台服务开关决定能否获取；播放器开关决定当前是否显示，两者都要检查。

## 显示“加载中”或“未找到”

系统按片名、年份和季集信息匹配，不确定时跳过，避免把其他影片或集数的弹幕混进来。某一集有弹幕不代表整季都有。

自定义来源首次抓取可能需要较长等待。先等当前请求结束，确认服务本身可用及影片季集信息正确，再重试；不要连续切换制造重复抓取。

弹幕失败或没有匹配结果不影响视频播放。关闭服务会取消获取并释放相关连接与缓存。
