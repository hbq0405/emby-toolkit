# 用户与权限

ETKN 使用自己的账号体系登录管理页面和内置媒体服务。管理员账号来自 Compose 中的 `ETKN_ADMIN_USERNAME` 与 `ETKN_ADMIN_PASSWORD`；普通用户可以通过邀请链接注册。

## 管理员

管理员可以：

- 创建、停用和删除用户。
- 创建权限模板，限制可见媒体库和内容分级。
- 生成一次性邀请链接并设置有效期。
- 设置用户是否为管理员、修改密码和维护 Telegram ID。
- 管理服务授权、任务、媒体库和系统配置。

## 普通用户

普通用户只能看到授权范围内的媒体和个人中心，可以维护自己的密码、头像、Telegram ID 和个人偏好。系统设置、任务治理、用户管理和媒体批处理只对管理员开放。

## 邀请链接

邀请链接只能按创建时的规则使用一次。注册时会套用指定模板；如果注册中途失败，ETKN 会清理未完成的账号状态。

## 账号和播放

管理账号与媒体服务账号属于同一套 ETKN 用户身份。播放记录、播放偏好和授权媒体库按用户保存，不需要先创建一套外部 Emby 账号。
