# 音乐库与歌单

ETKN 的网页客户端也能听音乐。音乐按自己的库与标签组织，不需要套用电影、剧集的识别方式。

## 准备音乐库

管理员进入 **媒体管理**，新建指定路径媒体库，选择音乐内容类型和实际音乐目录，刷新后在网页客户端打开该库。目录必须能被容器读取；扫描状态在任务中心查看。

优先把音频文件的专辑、歌手、曲名和曲序标签整理完整。缺少标签时，某些内容可能按文件名或文件夹显示，不要用影视元数据刷新来修复音乐标签。

## 按自己的习惯浏览

| 分类 | 用途 |
| --- | --- |
| 推荐 | 查看音乐推荐与最近内容 |
| 专辑 | 按专辑查看曲目和封面 |
| 歌手 | 查看歌手及其歌曲、专辑 |
| 歌曲 | 从歌曲列表选择播放 |
| 文件夹 | 沿目录查找内容 |
| 歌单 | 管理当前账号的个人歌单 |

专辑和歌手页提供播放全部、随机播放与循环播放等操作。播放列表与歌曲切换以当前页面提供的按钮为准。

## 创建歌单

1. 进入 **歌单**，填写名称并创建。
2. 从歌曲操作菜单选择加入歌单，也可以在添加时创建新歌单。
3. 回到歌单查看和播放已添加曲目。

歌单按账号保存。删除歌单只移除歌单本身，不删除歌曲文件。

## 封面和权限

具有管理权限的账号可在歌手或专辑页上传对应图片。删除整张专辑与删除歌单的范围不同，删除专辑前应阅读确认内容，核对将处理的媒体与文件。

音乐入口与可见内容取决于已配置的音乐库和用户权限。只有音乐文件被正确纳入库后，网页分类中才会出现相应内容。
