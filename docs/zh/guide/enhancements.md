# 增强功能

增强功能集中放置不属于每次入库必经步骤、但适合批量维护的工具。

## 封面生成

按媒体库配置封面样式、标题、角标、排序和图源，可在新入库或任务中批量更新。先保存配置，再执行生成任务；生成失败时在任务中心查看具体媒体库和图片来源。

## 监控上传

把本地目录映射到 115 目录，支持：

- 增量双向同步。
- 上传成功后删除本地暂存文件。
- 多组本地目录/115 目录映射。
- 按媒体扩展名和目录配置监控范围。

它适合把本地下载或暂存目录交给 115 管理，不等同于“扫描媒体库”。上传任务完成后仍可继续进入整理和入库流程。

## 自动打标

自动打标按媒体库和分级配置规则，为符合条件的媒体追加或移除标签。也可以执行一次性的手动标签操作。规则保存后，点击“执行已配置规则”才会创建任务。

媒体库和分级都留空时，规则会扫描全部可用媒体库。执行前建议先选小范围验证。

## 媒体去重

媒体去重会扫描重复媒体版本并生成计划，先看计划再确认清理：

1. 配置扫描媒体库和保留优先级。
2. 执行“扫描重复项”。
3. 检查每组重复版本和预计删除内容。
4. 逐组或批量确认清理。

清理会永久删除多余媒体文件，不能仅凭“文件名看起来一样”直接确认。单个版本删除也可能绕过普通规则，因此请先确认媒体版本和来源。

## 分享入库

直接粘贴 115 分享链接，每行一个。系统会检查分享状态、列出来源文件并把可识别文件接入整理任务。

- 分享入库不需要先转存到自己的 115 目录。
- 可以单独检查链接、重试入库或查看来源文件。
- 删除来源会停止关联任务，并删除该来源生成的本地 STRM/入库版本；其他来源仍在使用的版本保留。
- 自动删除失效链接只在明确失效时生效，网络异常不会直接删除。
