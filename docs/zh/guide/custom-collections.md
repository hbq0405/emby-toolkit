# 虚拟媒体库

虚拟媒体库是 ETKN 内置媒体服务提供的“自定义片单”。它把 TMDb 榜单、规则筛选、个人推荐或指定路径整理成一个可以浏览的媒体库。

## 支持的来源

- **列表**：从 TMDb 榜单、合集或手动选择的影视条目生成。
- **规则筛选**：按类型、标签、评分等条件筛选已有或可发现的内容。
- **个人推荐**：根据指定用户的观看偏好生成推荐库，是否可用取决于当前权益。
- **指定路径**：把指定目录作为一个媒体库来源。

## 使用方式

1. 管理员进入 **媒体管理**，打开媒体库配置。
2. 新建虚拟媒体库，选择来源类型并填写名称、内容类型和访问范围。
3. 保存后刷新该库。首次刷新会生成条目，后续可按需重新刷新。
4. 使用支持 Emby/Jellyfin 的客户端连接 ETKN 的媒体服务地址浏览。

虚拟媒体库默认通过 `8097` 提供媒体服务。管理页面和配置接口仍使用 `5257`。两个端口都要映射到客户端可以访问的地址。

## 常见操作

- 修改库的排序和展示顺序。
- 手动修正无法匹配的 TMDb 条目。
- 为单个库或全部虚拟库刷新内容。
- 生成或上传库封面。
- 为不同用户限制可见的媒体库。

虚拟媒体库只负责组织展示。条目真正入库、资源获取和任务执行仍由资源中心、订阅中心和核心入库流程负责。
