# 媒体库、分组与分面

管理员在 **媒体管理** 创建和配置媒体库；实际内容浏览、编辑与播放在网页客户端进行。

## 选择媒体库来源

| 来源 | 用途 |
| --- | --- |
| 榜单导入 | 内置榜单，或 RSS、豆瓣豆列、TMDb List/Discover |
| 规则筛选 | 按年份、评分、题材、演员、导演、语言等筛选 |
| 个人推荐 | 根据访问用户的播放与收藏历史生成结果 |
| 指定路径 | 将可访问的本地目录加入，按内容类型处理 |

内容类型包括电影、剧集、混合、视频和音乐。家庭视频使用视频型指定路径库，不必匹配影视 TMDb 身份；音乐使用音乐类型，见 [音乐库](/zh/guide/music)。

1. 点击 **新建媒体库**，选择来源与内容类型。
2. 填写名称、可见模板、路径或规则。
3. 按需设置条目上限、显示在最新媒体、缺图截图与章节截图。
4. 保存后对需要落地条目的榜单/指定路径库执行刷新，在任务中心查看结果。

规则筛选与个人推荐按查询实时生成，与榜单/路径的刷新方式不同。部分刷新、封面、推荐能力受权益限制，以页面提示为准。

## 把多个库放进一个分组

点击 **新建分组** 创建名称，再编辑媒体库，将 **所属分组** 设为该组。留空的媒体库直接显示在客户端首页。

- 分组用于组织展示，不移动媒体文件。
- 分组本身不占媒体库额度，子库仍分别计入账号上限。
- 分组可生成或上传专属封面；没有专属封面时使用首个可见子库的封面。
- 分组展示需要客户端支持，实际可见内容仍按用户权限过滤。
- 删除分组后，组内媒体库回到首页，不会因为删除分组而删除媒体库。

## 让首页更清楚

可拖动支持排序的媒体库调整顺序。每个库的 **显示在最新媒体** 开关决定其内容是否进入首页最新分区。

分组、媒体库、分面卡片各有自己的图片用途。需要更换组封面时，在分组行操作；更换媒体库封面时，在对应库行生成或上传。

## 在网页中分类浏览

打开某个媒体库，可按当前内容支持的 **类型、播出平台、出品公司** 进入分类页，再查看关联影片；实体路径库还提供文件夹浏览。

媒体详情中的平台或公司名称也可进入关联片单。是否出现某个入口取决于内容类型和元数据，缺失信息不会凭空补出分类。

## 编辑与维护媒体

管理员在网页媒体卡片或详情操作菜单中，可以按权限：

- 编辑标题、简介、分级和标签等元数据。
- 维护图片，搜索、上传、删除或调整可用图片。
- 刷新媒体、重建媒体信息或执行强制重处理。
- 查看并删除指定版本，或按确认范围删除媒体项。

重建 MediaInfo 与重处理元数据的作用不同；都不应当作“重新整理云端文件”的替代。修改 TMDb 身份或季集归属时，先看 [整理记录与纠错](/zh/guide/organize-records)。

## 默认音轨与字幕

基础设置 → 媒体库 → 默认音轨与字幕，设置全局优先级；个人中心可覆盖语言与字幕选择。默认流按当前配置与有效内封/外挂字幕计算，改偏好通常不需要重新扫描全库。
