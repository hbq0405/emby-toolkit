# 媒体管理

“媒体管理”是新版直接查看媒体库内容的地方，分为“媒体库”和“预览”两个视图。

## 媒体库

媒体库可以按榜单、规则、指定路径和个人推荐创建内置媒体服务中的媒体库：

- **榜单导入**：使用内置榜单或自定义 RSS、豆瓣豆列、TMDb List/Discover 来源。
- **规则筛选**：按类型、年份、评分、题材、演员、导演、语言等元数据实时筛选。
- **个人推荐**：根据当前访问用户的播放和收藏历史生成结果。
- **指定路径**：把某些本地视频目录作为媒体库来源。

可选择电影、剧集、混合内容或视频类型，也可以决定是否显示尚未入库的占位项。缺失条目可以进入统一订阅处理。

部分媒体库刷新、封面生成和个人推荐能力需要 Plus/Pro；页面会显示当前权益要求。

## 预览

预览页用于浏览内置媒体服务中的实际媒体项：

- 选择媒体库，搜索、排序和分页浏览。
- 按缺少海报或背景图筛选。
- 打开电影、剧集、季度和分集详情。
- 查看媒体版本、音视频流、字幕、图片和章节。
- 编辑标题、简介、分级、标签等元数据。
- 搜索/上传/替换图片，或为缺图项目生成截图。
- 刷新单项、当前媒体库或全部媒体库。
- 强制重处理元数据、演员表和媒体信息，或单独重建 MediaInfo。
- 清除片头片尾标记、删除媒体项或删除指定版本。

“强制重处理”不会自动重组 115 文件；“重建 MediaInfo”只更新媒体信息，不会修改元数据、图片或文件。删除操作会按照页面确认内容进入联动流程，请确认范围后再执行。

## 默认音轨和字幕

默认流不是旧 MediaInfo 中永久写死的字段。媒体库设置保存音轨/字幕优先级，媒体响应生成时会结合当前有效配置、内封流和外挂字幕实时计算默认项；个人字幕偏好可以覆盖全局字幕排序。

这意味着修改默认字幕偏好后，新播放请求会按新规则返回，不需要重新扫描所有媒体。
