# 智能追剧

智能追剧负责跟踪连载剧、补齐缺失集，并在完结后按策略处理整季洗版。

## 展示规则

- “追剧中”按季度展示追剧、暂停和待定状态。
- 季状态按本地已收集集数和外部信息判断，剧集完结列表按整剧聚合。
- 缺失集可以继续进入订阅需求，已完成的集不会因为普通刷新重复提交。

## 刷新行为

刷新重点检查新增集、元数据变化、图片变化和缺失项，不会无条件重新处理整部剧。开启分集截图或片头片尾分析时，相关工作会进入任务链，并可在任务详情中查看。

## 完结和洗版

完结判断会结合外部集数、本地收集情况以及订阅助手策略。完结洗版一致性没有通过时，会保留待洗版状态，不会把未确认完整的季度误判为已收口。

建议先配置 TMDb 和 MoviePilot，再在 **订阅中心 → 智能追剧** 中添加剧集；需要更细的完结守卫、下载巡检和快照维护时，再打开订阅助手增强版。
