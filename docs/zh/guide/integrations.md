# 外部服务集成

ETKN 的核心入库、任务中心和内置媒体服务可以独立运行。外部服务按用途接入，某个服务没有授权时，只会影响对应功能。

## TMDb、Fanart 与 Bangumi

这些服务用于标题、简介、日期、分级、人物、图片、合集、动画信息和影视探索。TMDb 是影视身份和主要元数据来源；Fanart 用于补充图片；Bangumi 可作为动画资料来源。网络代理在 **设置 → 网络** 中统一配置。

## AI

AI 可用于标题和简介翻译、分集简介、人物角色、文件名辅助识别以及只读智能排查。AI 暂时不可用时，核心整理会保留原始数据，不会因为 AI 失败而整条任务失效。

## Telegram Bot

Telegram Bot 分为通知和管理员交互两部分：

- 通知：发送入库、更新、洗版、转存、任务失败和播放等消息。
- 管理菜单：管理员可以在 Telegram 中查看任务菜单，直接触发已加入菜单的任务。
- 资源搜索：使用 `/search` 或 `/find` 搜索资源；选择影视项目后可以分页查看共享池、re0、频道等来源。
- 订阅和转存：在资源详情中可以订阅电影/季度，也可以选择资源转存 115 分享、Magnet、ED2K 或其他可识别直链。
- 交互控制：`/menu` 打开任务菜单，`/cancel` 取消当前搜索或选择流程。

配置 Bot Token、全局 Chat ID 和通知类型后，服务端会自动轮询 Bot 更新。管理员个人 Telegram ID 可在用户管理中维护。

### Telegram 频道监听不是 Bot

频道监听使用 Telegram 用户会话登录，按频道白名单、关键词或正则筛选消息并执行转存策略；它与上面的 Bot 通知/管理员菜单是两套独立链路。频道监听在 **资源中心 → 频道监听** 中配置，并把会话文件保存在配置目录。

## MoviePilot

MoviePilot 用于搜索、下载和订阅协作。ETKN 可以接收 MoviePilot 的订阅、下载和转移完成事件，也可以接管暂存文件的后续整理。转移完成不等于 ETKN 已入库，最终结果以任务中心和整理记录为准。

MoviePilot Webhook 地址在其配置页显示，当前入口是 ETKN 的 `/webhook`。

## 115 网盘与共享池

115 负责文件、分享、STRM 和直链播放；共享池负责资源索引、共享源、贡献点、秒传、转存和虚拟入库。两者均在资源中心或对应设置模块配置，不需要把外部 Emby 当作 ETKN 的必需依赖。
