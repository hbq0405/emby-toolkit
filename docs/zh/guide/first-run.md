# 首次配置

## 1. 创建 ETKN 管理员

第一次打开 `http://服务器IP:5257` 时，使用 Compose 中的 `ETKN_ADMIN_USERNAME` 和 `ETKN_ADMIN_PASSWORD` 登录。

如果密码留空，ETKN 会在首次启动时随机生成密码并打印一次。使用后请在个人中心修改密码。登录 ETKN 不需要先连接外部 Emby。

## 2. 授权 115

进入“服务授权”，按需要选择：

- **OpenAPI**：网页登录或自定义 AppID 扫码授权，适合常规管理和目录操作。
- **Cookie 接口**：扫码获取或手动录入 Cookie，可选择不同客户端类型。

两种接口由新版按场景使用和切换。播放、分享解析和小号池等功能还会根据配置选择合适的账号；页面不会回显完整凭据。

## 3. 配置数据源

在“设置中心”完成：

- **数据源**：TMDb 是主要影视识别和元数据来源；Fanart、Bangumi 按需要启用。
- **网络**：为 TMDb、GitHub、Telegram、re0 等外部请求配置代理。
- **AI**：用于翻译、文件名辅助识别、向量和任务智能排查，核心入库不依赖 AI 才能完成。
- **TG 通知**：填写 Bot Token、接收 Chat ID，并选择通知类型。

凭据以安全引用保存，页面只显示“已配置”状态，不把完整 Key 或 Token 返回给前端。

## 4. 配置媒体库

进入“设置中心 -> 媒体库”：

- 选择媒体库主目录。
- 填写客户端可以访问的 ETKN 地址。
- 确认媒体服务端口默认是 `8097`，并已在 Compose 映射。
- 按需要打开缺失/待播集占位、总集数显示和默认音轨/字幕规则。

新版自带兼容媒体服务。外部 Emby 不是新版主流程的必需服务；如果你仍使用其他媒体客户端或外部服务，请按客户端能访问的地址配置，不要把容器内地址直接填给客户端。

## 5. 配置 115 整理

进入“设置中心 -> 115 网盘”和“设置中心 -> 整理”：

1. 选择待整理目录。
2. 选择网盘媒体库根目录。
3. 设置未识别目录，给识别失败的内容留出人工处理位置。
4. 配置分类、命名模板、映射、词表、冲突处理和洗版优先级。
5. 先用一部电影或一整季剧集做小规模测试。

## 6. 第一次验收

在任务中心确认：

- 根任务已创建，剧集没有被拆成一集一个顶层任务。
- 识别、整理、元数据、媒体信息和媒体库发布阶段均有结果。
- 失败时能看到具体阶段和后续任务，而不是只显示“任务失败”。
- 在媒体管理中能搜索到结果，在播放中心能看到真实播放事件。
