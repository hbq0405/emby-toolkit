# 封面生成

封面生成位于 **增强功能 → 封面生成**，用于统一设置媒体库和虚拟媒体库的封面样式。

## 可以配置什么

- 使用哪些图片来源和备用图片。
- 标题、副标题、年份、评分等文字信息。
- 角标、清晰度、音频或版本标签。
- 不同媒体库是否启用，以及需要排除的媒体库。

## 使用方法

1. 先保存封面样式和图源配置。
2. 选择媒体库或虚拟媒体库。
3. 执行生成或等待对应任务运行。
4. 在任务中心查看进度，生成后的图片由 ETKN 图片仓库提供给媒体服务。

封面生成不负责识别媒体，也不会替代核心入库。图片生成失败时，可在媒体管理中重新刷新单个媒体项或重新生成对应库封面。
