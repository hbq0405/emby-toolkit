# 认识 ETKN

ETKN（ETKvNext）把资源获取、自动整理、订阅追更和媒体播放放进同一套系统。它有自己的媒体服务、网页客户端与原生 Android TV 客户端。

## 日常怎么用

1. **找到资源**：从共享池、Telegram 频道、MoviePilot、re0 或手动链接接入。
2. **整理入库**：识别、归类、生成 STRM，准备影视元数据与媒体信息。
3. **持续追更**：用追剧、演员、合集或榜单产生订阅需求。
4. **打开就看**：网页和 TV 浏览片库，切换版本、音轨、字幕并同步进度。
5. **跟踪结果**：任务中心看入库过程，播放中心看会话和统计。

已有本地视频、家庭视频和音乐也可以按对应内容类型加入，不必先搬进 115。

## 按需启用

- 内网自动缓存与官方客户端转码。
- 文本字幕翻译、简繁转换、双语与完整外挂保存。
- 内置或自定义弹幕服务。
- 媒体库分组、分面浏览、专属封面和多用户权限。
- 自动任务、封面生成、去重与监控上传。

详细入口见 [功能一览](/zh/introduction/features)。可选能力需要相应配置，有些功能受当前 Plus/Pro 权益和用户权限限制。

## 部署与数据

推荐使用公开 Docker 镜像和 PostgreSQL。管理、网页、媒体 API 统一走媒体端口，新部署默认 `8097`，`5257` 仅供容器内部使用。

PostgreSQL 保存媒体、配置、用户与任务；`/config` 和实际媒体目录需要持久化。ETKN 自带媒体服务，外部 Emby 不是主流程的前置条件。

## 这份文档适用什么版本

本站沿用旧版公开仓库承载，内容面向 ETKN 新版。新版源码仓库为私有，阅读文档与拉取公开镜像不需要源码访问权限。

本轮主要功能按 2026 年 11 月 11 日的实现核对。安装版本、系统权限、来源可用性和客户端能力可能影响入口；示例端口不能覆盖已有保存配置。
