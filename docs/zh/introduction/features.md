# 功能特色

## 资源到媒体库

新版的主线是“找到资源后持续跟踪它的处理结果”：

- 从 115 待整理目录、115 分享、共享池、re0、Telegram 频道或 MoviePilot 接收资源。
- 按电影、剧集、季度和分集归组，结合文件名、目录和外部身份识别。
- 应用分类、重命名、映射、词表和洗版规则。
- 生成 STRM、字幕和必要的图片/元数据资产。
- 继续处理 TMDb、Fanart、Bangumi、AI 翻译、媒体信息、截图和媒体库刷新。
- 将成功、拦截、未识别和失败都写入整理记录与任务历史。

一整季剧集通常是一个根任务，分集是任务内部的处理项；因此任务中心不会把每一集都显示成独立的顶层任务。

## 资源中心

资源中心按来源拆开，便于知道资源从哪里来、为什么没有进入下一步：

- 共享池：浏览中心资源、我的共享源、虚拟入库和贡献点流水。
- 频道监听：授权 Telegram 用户会话，按白名单、关键词、正则和转存方式监听频道。
- MoviePilot：接收订阅、下载和整理事件，也可以让 ETKN 接管暂存文件和后续入库。
- re0：按 TMDb ID 搜索电影或剧集，按积分、体积、分辨率和字幕条件筛选后获取。
- Telegram Bot：管理员可搜索资源、选择资源、订阅、转存分享链接和执行任务。

## 订阅和媒体库

订阅中心提供统一需求列表、来源优先级和状态视图：

- 智能追剧按季度追踪连载和缺集。
- 演员订阅持续检查关注演员的新作品。
- 合集补齐根据 TMDb 合集成员生成缺失需求。
- 影视探索支持筛选、查看媒体详情和按电影/季度订阅。
- 虚拟媒体库支持榜单导入、规则筛选、个人推荐和指定路径。

## 维护和排障

任务中心提供当前任务、历史任务、自动任务和任务工具箱；任务详情可以看到阶段时间线、完整日志、后续任务和失败原因。启用 AI 后，智能排查只读取白名单状态与脱敏日志，不执行任意 SQL、Shell、Docker 命令，也不修改配置或任务。

媒体管理和增强功能还提供：

- 按媒体库浏览、搜索、排序、分页和图片完整性筛选。
- 批量刷新、强制重处理、重建 MediaInfo、补图和片头片尾处理。
- 元数据、图片、评分、版本和媒体项删除操作。
- 封面生成、监控上传、自动打标、媒体去重和分享入库。
- 正在播放、播放记录和最近 7 天统计。

## 权限和权益

管理员负责服务授权、系统设置、用户模板、邀请链接和任务治理。普通用户只看到被授权的个人入口。虚拟媒体库刷新、封面批处理、共享池部分能力和虚拟入库等功能会按 Plus/Pro 权益限制，页面会直接显示所需权益。
