## 使用前先确认

自动缓存、转码、AI 字幕与弹幕分别配置；某个开关开启不代表其他功能也已开启。远程资源默认使用直链，内网缓存与官方转码按条件生效。

原盘、HDR、音频和字幕格式的兼容性取决于实际设备与片源。第三方 Emby/Jellyfin 兼容客户端可使用基础媒体能力，官方 Web/TV 的专属功能不能视为第三方必然支持。

资源共享、虚拟库、推荐、影视探索等部分能力按权益限制，账号还需要对应权限。以页面实际提示为准，不在文档中固化配额或价格。
